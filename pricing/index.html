What's the real difference?

It's not just about features — it's about workflow.

Free (Self-Hosted)

Your trade memory lives on your local machine. Switch devices? Start from zero. Great for single-machine workflows and developers who love full control.

Paid (Hosted API)

Trade memory stored in the cloud at mcp.mnemox.ai. Desktop, laptop, VPS — your agent remembers everywhere. No setup, no databases, no backups. Just works.

How does billing work?

  • Each store_trade() call = 1 credit
  • recall_trades() and performance() are free (unlimited reads)
  • Credits reset monthly — if you hit your limit, the API returns 429 Too Many Requests
  • No overage charges. No surprise bills. Just a hard monthly cap.

Frequently Asked Questions

Everything you need to know about TradeMemory pricing.

What happens to my data if I upgrade from Free to Paid?

Nothing. Your local trades stay local. When you start using the hosted API, it's a separate cloud database. You can manually migrate trades via the API if you want continuity.

Can I cancel anytime?

Yes. Cancel anytime from your dashboard. Your data remains accessible until the end of your billing period, then it's archived (we keep a 30-day backup). You can always export before canceling.

Which platforms are supported?

TradeMemory works with any platform that can send trade data: MT5 (via mt5_sync.py), Binance, Alpaca, Interactive Brokers, or any custom source via our REST API or MCP tools.

Where is my data stored?

Hosted API data is stored on Render's US infrastructure with automated daily backups (30-day retention). Free tier data is stored locally on your machine — you control the location.
